# Арабский язык: от буквы к смыслу

Статический тренажёр арабского алфавита на HTML, CSS и JavaScript. Сторонние фреймворки и сборка не нужны.

## Файлы сайта

- `index.html` — главная страница.
- `page1.html`–`page9.html` — девять уроков с полным набором из 28 букв.
- `style.css` — общие стили и десять цветовых тем.
- `app.js` — отметки об изученных буквах и сохранение прогресса в браузере.
- `favicon.svg` — иконка сайта.
- `manus-routes.json` — перечень страниц.

Отметки обучения сохраняются в локальном хранилище браузера на текущем устройстве. Для отображения арабского шрифта и дополнительных гарнитур сайт загружает Google Fonts; если сеть недоступна, используются системные шрифты из CSS.

## Локальный просмотр

Откройте `index.html` в браузере или запустите в этой папке простой статический сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## GitHub Pages

Загрузите файлы HTML, CSS, JS, SVG и JSON в корень репозитория. В настройках репозитория выберите **Settings → Pages**, укажите ветку и каталог `/ (root)`. Стартовая страница сайта — `index.html`.
